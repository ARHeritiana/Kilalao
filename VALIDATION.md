# Kilalao 1.1.0 validation

Validated on 2026-10-11. This release implements the requested mobile UI redesign, game animations, and interactive 3D cubes.

## Completed local checks

- 62 automated engine and DOM interaction tests passed. All 24 game screens and 72 learning sections render without JavaScript errors.
- New coverage checks Play/Learn navigation and the action dock, both 3D cube sizes, every rendered sticker against the engine after face turns, independent CSS rotation geometry for all twelve turns, orbit gestures and pointer ownership, actual Hanoi disk movement, rapid cube moves, synchronous saving, Undo, reduced motion, and inert removal ghosts.
- JavaScript syntax checks passed. Browser test discovery finds eight checks.
- npm audit reported zero known vulnerabilities in the 42 development packages. No JavaScript runtime dependencies are bundled.
- Android `assembleDebug` and `lintDebug` passed. Lint reports no issues.
- Android build-tools verified the APK signature and package metadata: `mg.kilalao.app`, version 1.1.0, version code 3, minimum API 26, target API 35, no requested permissions.
- Every bundled asset was compared byte-for-byte with its final source file.
- `APK/SHA256SUMS` includes the previous 1.0.1 build and the new 1.1.0 build.

## Browser and device limits

The local headless browser cannot launch because the environment blocks its process-singleton socket. No local browser screenshots, physical-device run, or emulator run were completed. DOM and geometry tests do not establish device appearance or animation performance.

GitHub Actions now includes Playwright checks for all game screens at 320, 360, 390, 480, and 800 CSS pixels, large navigation/action targets, horizontal overflow, real move animations, reduced motion, 3D cube controls, and phone screenshots. The remote result is recorded separately after the run; these checks must not be described as passing solely because they are configured.

The previous Actions run failed while the Android setup action requested Google's removed `tools` package. The workflow now requests only `platform-tools`, `platforms;android-35`, and `build-tools;35.0.0` explicitly.

## Signing and upgrade

The new APK certificate SHA-256 is `00e8a8ff965337eaeffae0fe9866e89fb9580322e2cf2037a6d6d5fedaf59b94`; it differs from 1.0.x. Android cannot update the older APK in place. The new development key is retained separately from GitHub source for future builds; it is not a production signing key. Keep signing keys out of this repository. APKs generated by GitHub Actions use that runner's debug key and should not be assumed interchangeable with the bundled APK.
